# Lista de Tarefas com Flask

## Descrição

Este projeto foi desenvolvido utilizando a biblioteca **Flask** para criar uma aplicação web simples de gerenciamento de tarefas (To-Do List).

A aplicação permite que o usuário adicione novas tarefas e remova tarefas existentes através de uma interface web.

## Funcionalidades

* Adicionar tarefas.
* Visualizar todas as tarefas cadastradas.
* Remover tarefas da lista.
* Interface simples acessível pelo navegador.

## Tecnologias utilizadas

* Python 3
* Flask

## Como executar o projeto

1. Instale as dependências:

```bash
pip install -r requirements.txt
```

2. Execute o projeto:

```bash
python app.py
```

3. Abra o navegador e acesse:

```
http://127.0.0.1:5000
```
